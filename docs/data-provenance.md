# OceanLens India — data provenance

Every layer the interface can render is classified here. The application, the
manifest (`public/data/real/manifest.json`), the on-screen provenance panel and
the demo script use the same vocabulary:

| status | meaning |
|---|---|
| `Real source, locally cached` | downloaded from a real public source, cached in-repo |
| `Precomputed from real source` | computed offline from real source data (subset, unit-normalised) |
| `Derived from real source` | computed at runtime from real cached data (e.g. an isosurface) |
| `Synthetic test fixture` | deterministic, for tests/stories only — never shown in the app |
| `Not available in MVP` | investigated, no usable real source prepared in time |
| `Planned extension` | real source understood, out of scope for this build |

Nothing is labelled *verified*, *official*, *live* or *real-time*. Identifiers
shown in the UI are `DEMO-` prefixed.

---

## Demonstration window

**2023-09-25 00:00 UTC → 2023-10-05 00:00 UTC**, 11 daily steps. Labelled in
the UI as **“Historical demonstration window”**.

Chosen because it is the densest real INCOIS Argo coverage of the Bay of Bengal
that also falls inside HYCOM `expt_93.0`'s time span (2018-12-04 → 2024-09-05).
Candidate dates in late Aug / early Sep 2023 were harvested and compared; late
September has the most usable INCOIS profiles and a natural west–east float line
across the basin at ~13 °N on 28–29 Sep, plus a single float (WMO 6990608)
profiling almost daily near 8.5 °N 89.9 °E — a genuine near-daily time series.

The original artboard's "03 Sep 2026" date is **not** used; the model data for
2026 does not exist in a real public archive.

## Layer classification

| Layer | Class | Source | Notes |
|---|---|---|---|
| Model temperature | Precomputed from real source | HYCOM GOFS 3.1 `ts3z` | NCSS subset, unit-unpacked |
| Model salinity | Precomputed from real source | HYCOM GOFS 3.1 `ts3z` | as above |
| Model currents (u/v) | *(see status in manifest)* | HYCOM GOFS 3.1 `uv3z` | included only if the `uv3z` subset was retrieved and validated; otherwise `Not available in MVP` with a planned adapter |
| Argo profiles (T, S) | Real source, locally cached | Argo GDAC — `dac/incois/`, `dac/csio/`, `dac/coriolis/` | delayed-mode where available |
| Argo QC flags | Real source, locally cached | Argo GDAC | 1/2/3/4 → GOOD/PROBABLY_GOOD/SUSPECT/BAD |
| Model–obs collocation | Derived from real source | computed | haversine distance, JULD−model time offset, RMSE, mean bias, band agreement — all from cached arrays |
| Isosurface | Derived from real source | computed from HYCOM temperature | marching-squares at render time |
| BGC-Argo | Not available in MVP | — | no BGC float in window/region carried usable co-located T/S + BGC levels |
| Glider sections | Planned extension | — | no open real glider section identified for this region/window |
| CTD casts | Planned extension | — | no open real CTD cast identified for this region/window |
| Satellite SST | Planned extension | GHRSST L4 is obtainable | not yet prepared into the cache |
| Satellite chlorophyll | Planned extension | ocean-colour L3/L4 obtainable | not yet prepared into the cache |
| Coastline / bathymetry / EEZ | Planned extension (Phase 4) | Natural Earth; generalised contours | geographic context, added with the scene |
| INCOIS advisories | Planned extension | — | no stable public advisory feed integrated |
| ML anomaly layer | Planned extension | — | no trained model; future only |

The exact counts, file names, checksums, retrieval timestamps, variable lists,
units, coordinate systems, depth/time ranges, QC semantics and the full ordered
list of transformations for each real source are in
`public/data/real/manifest.json`, regenerated by
`scripts/prepare-real-data.mjs` and gated by `scripts/validate-real-data.mjs`.

## How to regenerate

```bash
node scripts/prepare-real-data.mjs            # download + normalise
node scripts/validate-real-data.mjs           # gate
```

Raw downloads land in `.cache/raw/` (git-ignored). The normalised cache in
`public/data/real/` is committed and is the only thing the browser reads. No
network access is required to run the application after preparation.
